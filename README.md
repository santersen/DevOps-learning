# DevOps-learning
## Overview 
This repository is created to documenting learning process in IT Infrastructure and DevOps concepts.
### Key Topics and Focus
- **Linux Fundamentals:** Basic bash comands, navigation, file permissions, main tools.
- **Docker(Containerization):** Difference between containers and VMs, images, basic deployment.
- **Data Analytics and BI:** Basic concepts of data processing and system monitoring.
- **CI/CD and Cloud Basics:** Fundamentals of continuous integration, deployment pipelines and server management.
